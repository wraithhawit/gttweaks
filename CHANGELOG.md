This repository begins with the existing 0.25.0 source snapshot. Earlier development happened locally; the entries below summarize the immediately preceding changes and do not imply reconstructed Git history.

## 0.29.0 (stable)

- Remove duplicate camera-position subtraction in schema rendering, keeping blocks, block entities, highlighting and picking on the same transform.
- Aim the camera at the geometric block center and compensate fitted distance for the removed duplicate translation.
- Three matrix regression tests pass alongside the five existing tests. Confirmed in game: blocks, highlighting and picking stay aligned while rotating and panning. Scroll zoom felt far too slow (issue #2, next entry).
- Scroll-wheel zoom in multiblock previews is 10x faster by default, set by a new client config option `previewZoomSpeed` (`config/gttweaks-client.toml`, also under the mod list's Config button; range 0.1–100, 1.0 = ModularUI's speed). ModularUI 3.3.1's `SchemaWidget.onMouseScrolled` moves the camera 1/12 block per notch (`incrementScale(-scroll / 12)`, and `scale` is the camera distance). With fitted distances of dozens of blocks and the pivot fix halving apparent speed, that took hundreds of notches. `SchemaScrollZoomSpeedMixin` multiplies only that call's argument; a value that is not a positive finite number leaves ModularUI's step unchanged. Three unit tests cover the step. Confirmed in game: zoom is much faster, and the setting works from the mod list's Config screen.
- Restore the 1.20 Assembly Line recipe page in EMI. The 8.0 snapshot still ships `assembly_line.rtui` but `loadRecipeTypeUIFromFile` throws, so a custom layout rebuilds it from that file's positions: 4x4 item grid, connector bar, four fluids, output, arrow and research slot. Confirmed in-game.
- Put the EU "Total / Usage" lines back on that page; the custom layout skipped the builder that creates them. Confirmed in-game.
- Fill the research slot with each research entry's data item, as 1.20 did, and drop the snapshot's separate `research_info` row on that page. The empty slot shows the data-orb icon under EMI's hover highlight (confirmed in-game); confirmed in game on a recipe that needs research.
- Accept GregTech 7.x bare capability keys (`"item"`, `"fluid"`, `"eu"`) in recipe JSON by reading them as `gtceu:` ids. The 8.0 snapshot resolved them to `minecraft:item` and rejected the recipe, so none of Productive Bees' 27 GregTech bee recipes loaded. Applied to `RecipeCapability`'s content codecs, the serializer's chance-logic map and KubeJS's `RecipeCapabilityComponent`; namespaced keys and encoding are unchanged. Headless server: bee recipe parse errors 27 → 0, KubeJS component warnings on them 81 → 0. Four unit tests cover the key handling. Confirmed in game: the GregTech bee machine recipes show in EMI.

- Pack script (instance KubeJS, mirrored in `pack/kubejs/server_scripts/gttweaks/progression_skips.js`): remove Modern Industrialization's titanium dust → hot ingot recipe (`materials/titanium/blast_furnace/dust`).
